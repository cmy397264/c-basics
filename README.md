# Study_C — 42 La Piscine

42 경산(Gyeongsan) La Piscine(입학 선발 과정)에서 풀었던 Shell·C 과제 모음입니다.

| 디렉터리 | 내용 |
|---|---|
| `sh00`, `sh01` | Shell 기초 — 파일 권한, git, find/ls 등 명령어 활용 |
| `c00` ~ `c11` | C 기초 — 출력, 포인터, 문자열, 재귀, 메모리 할당, 함수 포인터 등 |
| `r00` | Rush 준비용 연습 (`ft_putchar`) |

각 `exNN` 디렉터리가 하나의 문제이며, `*git`, `*FINAL` 디렉터리는 제출 시점별 스냅샷입니다.

```bash
cc -Wall -Wextra -Werror ex00/*.c -o a.out
```
