# Study_C — C 언어 기초 공부

리눅스 환경에서 Shell과 C 언어 기초를 단계별로 공부한 저장소입니다.

| 디렉터리 | 내용 |
|---|---|
| `sh00`, `sh01` | Shell 기초 — 파일 권한, git, find/ls 등 명령어 활용 |
| `c00` ~ `c11` | C 기초 — 출력, 포인터, 문자열, 재귀, 메모리 할당, 함수 포인터 등 |
| `r00` | `write`로 문자 출력 연습 (`ft_putchar`) |

각 `exNN` 디렉터리가 하나의 문제이며, `*git`, `*FINAL` 디렉터리는 단계별 정리본입니다.

```bash
cc -Wall -Wextra -Werror ex00/*.c -o a.out
```
